# Development Roadmap — 호텔 재고 관리 시스템

> 현재 코드 분석에서 식별된 미구현/개선 항목 정리.

---

## 현재 버전: v10 (Schema Version)

---

## 미구현 기능 (코드에서 확인됨)

### Priority 1 (비즈니스 핵심)
| 기능 | 상태 | 설명 |
|------|------|------|
| 반품 처리 | ❌ | `VALID_TRANSACTION_TYPES`에 "반품" 없음 |
| 발주서 생성 | ❌ | 발주점 계산은 있으나 발주서 생성/출력 미구현 |
| 거래 수정/삭제 | ❌ | Web App에서 등록된 거래 수정/삭제 기능 없음 |

### Priority 2 (운영 개선)
| 기능 | 상태 | 설명 |
|------|------|------|
| 재고 조정 | ❌ | 실사 결과 반영을 위한 직접 조정 기능 |
| 보고서/리포트 | ❌ | 월별/품목별 통계 리포트 |
| 알림 고도화 | 부분 | 이메일 알림은 있으나 Slack 등 다채널 없음 |
| 공급업체 관리 | ❌ | 품목별 공급업체 연결 기능 |

### Priority 3 (기술 개선)
| 기능 | 상태 | 설명 |
|------|------|------|
| DEV/PROD 분리 | ❌ | 단일 프로젝트, 환경 분리 없음 |
| 자동 테스트 | ❌ | Unit/E2E 테스트 코드 없음 |
| 에러 모니터링 | 부분 | System_Logs 시트 있으나 대시보드화 없음 |
| API Rate Limiting | ❌ | 로그인 외 API 호출 제한 없음 |

| 버전 | 기능 |
|------|------|
| v1 | 기본 재고관리, 입출고 |

| v9 | 미사용 품목 필터링, 서버사이드 검색, 태그ID 검증, 소프트 삭제 |
| v10 | 매직넘버 상수화, 배치 쓰기, LockService 확대, CacheManager 최적화 |

## 기술 부채 (Technical Debt)

| 항목 | 위험도 | 설명 |
|------|--------|------|

| hooks.json clasp push | Medium | CI/CD와 충돌 가능성 |
