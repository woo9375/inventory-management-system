# Security & RBAC Rules (SSOT)

이 문서는 AI가 접근 제어 로직을 작성하거나 시스템 보안 요소를 다룰 때 지켜야 할 **최소한의 필수 보안 규칙**만 정의합니다.

> **구체적인 권한 매트릭스, 역할별 상세 정책, 인증 메커니즘은 단일 진실 공급원(SSOT)인 `Docs/Security.md`를 참조하십시오.**

## 절대 금지 및 필수 원칙
1. **인가 우회 금지**: 사용자 입출력 등 데이터 처리 함수는 클라이언트(브라우저) 측 검증에 의존하지 말고, 서버 측(`src/*.gs`)에서 항상 세션 사용자의 권한(Role)과 업장(Location Scope)을 재검증해야 합니다.
2. **시크릿 하드코딩 금지**: API 키, 토큰, 비밀번호 등 민감 정보는 절대 소스 코드 내에 문자열로 하드코딩하지 마십시오. 오직 `ScriptProperties`를 통해서만 주입받아야 합니다.
3. **오류 정보 노출 제한**: 클라이언트 측으로 반환되는 에러 메시지에는 스택 트레이스나 내부 시스템 정보(예: 데이터베이스 구조, 로컬 파일 경로 등)가 절대 노출되지 않도록 해야 합니다. (`System_Logs` 시트에만 기록)
4. **접근 권한 격리**: Staff 권한을 가진 사용자가 API 조작 등을 통해 자신에게 할당되지 않은 업장의 데이터를 조회하거나 수정할 수 없도록 격리해야 합니다.
