# Code Conventions Rules (SSOT)

이 문서는 AI가 Google Apps Script 환경에서 코드를 작성할 때 지켜야 할 **최소한의 필수 코딩 제약**만 정의합니다.

> **상세한 네이밍 규약, API 응답 패턴, 모듈별 책임 등은 단일 진실 공급원(SSOT)인 `Docs/CodingRules.md`를 참조하십시오.**

## 절대 금지 및 필수 원칙
1. **상수 하드코딩 금지**: 시트명, 색상, 컬럼 번호, 역할(Role) 등 모든 설정 상수는 절대 분산하여 하드코딩하지 마십시오. 오직 `Config.gs`에서만 정의 및 수정되어야 합니다.
2. **배치 I/O 필수**: `getValue()`, `setValue()`를 반복문 내에서 절대 호출하지 마십시오. 반드시 `getValues()`, `setValues()` 배열을 사용한 배치 처리를 구현해야 합니다 (Apps Script 쿼터 제한 회피).
3. **프라이빗 함수 패턴**: 클라이언트(HTML)에서 직접 호출되어서는 안 되는 내부 헬퍼 함수는 반드시 언더스코어(`_`)로 시작하는 이름(예: `_hashPassword()`)을 가져야 합니다.
4. **전역 오염 방지**: `var` 대신 `const`와 `let`을 사용하고, 다른 모듈의 변수를 덮어쓰지 않도록 전역 네임스페이스 오염을 최소화하십시오.
