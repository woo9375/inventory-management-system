C-1업장 = 컨텍스트 칩

지금의 2px 블루 대형 버튼(Index.html:215)을 제목 옆 pill로. 클릭하면 기존 openShopSelectionModal() 그대로. 어느 업장에 기록하는지는 항상 보이되, 버튼 위계에서는 빠진다.

C-2폼 4열 고정 · 인라인 span 제거

auto-fit 대신 PC 4열 고정. 품목명 검색은 .form-group--wide(2열)로 넓혀 자동완성이 읽히게. 태블릿 2열·모바일 1열에서는 wide가 전체 폭 — P0 1·2번 결함이 여기서 함께 해결된다.

C-3카드 푸터에 주 액션

솔리드 블루 기록 저장은 이 화면에서 유일. 옆에 outline 초기화. 단축키 힌트는 텍스트만 (기능은 이미 Enter 저장이 있는지 확인 후 결정).

C-4배너 → 캡션

Index.html:279 네이비 배너 삭제. "최근 50건 · 최신순"을 카드 제목 옆 캡션으로, 건수는 우측.

C-5테이블 정렬 · 구분 pill

텍스트 좌측, 수량 우측 tabular-nums, 구분은 .status-badge 재사용 — 입고 normal(초록) · 출고 primary(블루) · 폐기 risk(로즈). 거래ID·품목코드는 모노스페이스 muted. 렌더 위치 JS_Tx.html 테이블 생성부.

C-6구분 세그먼트 (옵션)

select 한 번 열고 고르는 대신 클릭 한 번. #txType select는 숨긴 채 유지하고 버튼이 값을 넣는 JS 10줄. 위 토글로 select 버전과 비교. 빼도 나머지에 영향 없음.

C-7관리자 액션은 「관리」 드롭다운

시트 동기화·일괄 업로드는 outline으로 노출. 신규 내역 취합·수동 월마감(파괴적, 드묾)은 admin 전용 드롭다운 안으로. 헤더가 5개 버튼 → 3개.

②이모지 vs Lucide

이모지 모양은 OS가 정한다(Windows = Segoe UI Emoji, 캡처의 그 모양). "더 예쁜 이모지"는 폰트(Noto Color Emoji 10MB급)를 실어야 해 GAS에 부적합. Lucide는 단색 선형이라 활성 탭에서 블루로 물들고 굵기가 글자와 맞는다 — shadcn 벤치마크가 쓰는 세트. 위 토글로 비교.
