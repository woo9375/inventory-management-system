# 🏨 호텔덕구온천 재고 관리 시스템 v1.0.0
> Google Apps Script + CLASP 기반 서버리스 웹 애플리케이션

---

## 📌 프로젝트 소개
호텔덕구온천의 소모품 및 자재 입출고, 재고 관리, 자동 발주점 계산, 시즌별 안전재고 조절을 하나의 시스템으로 완벽하게 통합 관리하는 전사적 재고 솔루션입니다.
v1.0.0 정식 릴리즈를 통해 데이터 대량 처리, 모듈화, 과거 데이터 분리 보관 등 엔터프라이즈급 성능 최적화가 적용되었습니다.

### 🌟 핵심 기능 (Core Features)

| 기능 분류 | 세부 기능 및 설명 |
|------|------|
| **📊 스마트 대시보드** | KPI 카드 (위험/발주필요/정상 상태 실시간 집계), 경고 품목 원클릭 확인 |
| **📝 트랜잭션 관리** | 업장별 입고/출고/폐기 기록, 트랜잭션 ID 자동 생성 및 무결성 보장 |
| **🗂️ 품목 마스터** | 단건 및 **CSV 대량 업로드** 지원, 목표유지일수 기반 자동 발주량 계산 |
| **🗓️ 선입선출 월마감** | 매월 과거 데이터를 드라이브로 백업하고, **FIFO 알고리즘**을 통해 정확한 잔여 로트 단가 및 수량 이월 |
| **⚙️ 시스템 설정** | 업장 관리, 시즌 설정 (안전재고 배수 보정), 기초 데이터(단위/분류) 동적 관리 |
| **🔐 RBAC 보안** | 관리자(Admin), 매니저(Manager), 담당자(Staff) 역할별 접근 제어 및 기능 제한 |
| **🔄 데이터 동기화** | 증분 동기화(Incremental Sync) 및 일일 자정 배치 처리를 통한 성능 극대화 |

## 📁 아키텍처 및 폴더 구조 (모듈화 완료)
프론트엔드 HTML/JS 파일들이 기능별로 완벽하게 분리(Decoupled)되어 유지보수성이 극대화되었습니다.

```
inventory_management_system/
├── README.md                ← 시스템 소개서
└── src/                     ← GAS 배포용 소스 디렉터리
    ├── appsscript.json      ← 프로젝트 매니페스트 (타임존, 권한)
    │
    ├── [서버 백엔드]
    │── Config.gs            ← 전역 상수, 환경 변수 (폴더 ID 등) 설정
    │── Code.gs              ← 초기 설치 및 진입점
    │── WebApp.gs            ← 웹 API 라우터 (프론트엔드 ↔ 백엔드)
    │── StockEngine.gs       ← FIFO 알고리즘 및 재고, 발주점 계산 핵심 엔진
    │── Archive.gs           ← 마감/이월 처리 및 CSV 백업 모듈
    │── RBAC.gs              ← 권한 부여 및 토큰 인증 시스템
    │── Dashboard.gs         ← 대시보드 통계 집계 모듈
    │
    ├── [클라이언트 프론트엔드]
    │── Index.html           ← 메인 레이아웃 템플릿
    │── Stylesheet.html      ← 글로벌 CSS 및 컴포넌트 스타일
    │── JS_Auth.html         ← 인증 및 세션 관리 JS
    │── JS_UI.html           ← 공통 UI, 모달, 네비게이션 JS
    │── JS_Tx.html           ← 입출고 트랜잭션 처리 JS
    │── JS_Master.html       ← 품목 마스터 및 대량 업로드 JS
    │── JS_Config.html       ← 시스템 설정 및 월마감 JS
    │── JS_BaseData.html     ← 기초데이터 CRUD JS
```

## 🚀 설치 및 배포 가이드

### 1. 사전 요구사항
- [Node.js](https://nodejs.org/) 설치 완료 환경
- 구글 계정 및 빈 Google Apps Script 프로젝트 생성
- 데이터를 보관할 구글 드라이브 폴더 생성 및 폴더 ID 확인

### 2. CLASP 연동 및 푸시
```bash
# 구글 계정 연동
clasp login

# .clasp.json 파일 생성 후 scriptId 입력
# (Apps Script 설정 탭에서 확인 가능)

# 소스코드 구글 서버로 푸시
clasp push
```

### 3. 시스템 초기화 및 배포
1. Apps Script 에디터 접속
2. `Config.gs` 상단의 `ARCHIVE_FOLDER_ID`를 본인의 구글 드라이브 폴더 ID로 변경
3. `Code.gs` 파일에서 `createAll` 함수를 선택하고 **실행** (초기 시트 및 관리자 계정 생성)
4. 우측 상단 **[배포] -> [새 배포]** 클릭
5. 웹 앱(Web App) 유형으로 설정, 접근 권한을 "모든 사용자" 또는 "도메인 사용자"로 지정 후 배포!
