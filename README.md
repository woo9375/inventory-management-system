# 🏨 호텔덕구온천 재고 관리 시스템 v1.0.0
> Google Apps Script 기반 통합 구매/재고 관리 웹 애플리케이션

---

## 📌 1. 프로그램 개요 및 목적
호텔덕구온천의 소모품 및 자재 입출고, 재고 관리, 자동 발주점 계산, 시즌별 안전재고 조절을 하나의 시스템으로 완벽하게 통합 관리하는 솔루션입니다. 
각 업장에서 입력한 데이터가 중앙으로 자동 취합되며, 정확한 재고 자산 평가를 위해 선입선출(FIFO) 기반의 월 마감 기능을 제공합니다.

---

## 👥 2. 사용자별 권한 및 역할 (RBAC)
본 시스템은 직무에 따라 화면과 권한이 다르게 노출됩니다.

1. **최고 관리자 (Admin)**: 시스템 설정, 사용자 계정 생성, 권한 부여, 신규 업장 시트 생성, 시스템 데이터 수동 백업 및 월 마감 실행 권한을 갖습니다.
2. **구매 총괄 / 매니저 (Manager)**: 품목 마스터(신규 자재) 등록 및 수정, 전 업장의 통합 대시보드 조회, 대량 CSV 업로드, 전체 입출고 내역 열람이 가능합니다.
3. **각 업장 담당자 (Staff)**: 본인이 소속된 업장의 입출고 내역 입력 및 조회만 가능하며, 품목 마스터 수정이나 시스템 설정에는 접근할 수 없습니다.

## 💡 3. 핵심 비즈니스 로직 이해하기 (필독)
시스템을 정확하게 사용하기 위해 실무자 및 제작자가 반드시 알아야 할 3가지 핵심 구조입니다.

### ① 🗓️ 월 마감과 선입선출 (FIFO) 로직
매월 말일, 시스템 관리자가 '월 마감'을 실행하면 한 달간의 입출고 기록이 별도의 보관(Archive) 파일로 이동합니다. 이때 **단순히 수량만 뭉뚱그려서 이월하지 않습니다.**

- **로트(Lot)별 분할 이월**: 10일에 1,000원에 10개 입고, 20일에 1,200원에 20개 입고된 사과가 있다고 가정합니다. 총 5개가 소비되었다면, 남은 재고는 25개입니다.
- 시스템은 이 25개를 하나로 합치지 않고, `1,000원짜리 5개`, `1,200원짜리 20개` 로 각각 **고유의 단가를 유지한 채 새로운 입고 기록으로 다음 달 메인 시트에 기록**합니다.
- 따라서 마감을 여러 번 진행해도 구매 단가가 섞이지 않으며 완벽한 **선입선출 기반의 재고 자산 평가**가 가능합니다.

### ② ⚡ 누락 데이터 자동 취합 (구: 증분 동기화)
다수의 업장 담당자가 동시에 각자의 구글 시트에서 입출고를 입력하다 보면 구글 서버의 한계로 중앙(통합 시트)에 데이터가 100% 실시간으로 반영되지 않을 수 있습니다.
- 이를 방지하기 위해 매 15분마다 백그라운드 시스템이 모든 업장을 순회하며 **'메인에 아직 기록되지 않은 새로운 거래 내역(고유 거래 ID 기준)'을 찾아내 강제로 취합**합니다.
- 관리자 화면 좌측 하단의 '마지막 취합' 시간을 통해 시스템이 정상 작동 중인지 언제든 확인할 수 있습니다.

### ③ 📅 시즌별 안전재고 보정
호텔업의 특성상 성수기(여름, 겨울)와 비수기의 소모품 사용량이 크게 다릅니다.
- '시즌 관리' 메뉴에서 특정 기간(예: 7/15 ~ 8/15)을 '성수기'로 지정하고 **배수(Multiplier)**를 1.5로 설정할 수 있습니다.
- 해당 기간이 되면 대시보드의 모든 품목의 '안전 재고'와 '적정 발주량' 시스템 요구치가 자동으로 1.5배 상향 조정되어, 성수기 재고 부족 사태를 시스템이 선제적으로 방어합니다.

## 🚀 4. 초기 설치 및 배포 가이드 (제작자용)

### 1. 사전 요구사항
- [Node.js](https://nodejs.org/) 설치 완료 환경 및 `clasp` 설치
- 데이터를 보관할 구글 드라이브 폴더 생성 및 폴더 ID 확인

### 2. CLASP 연동 및 배포
```bash
# 구글 계정 연동 및 클론
clasp login

# 설정 파일 (Config.gs) 내 ARCHIVE_FOLDER_ID 및 시스템 변수 업데이트
# 소스코드 푸시
clasp push
```

### 3. 시스템 초기화
1. Apps Script 에디터 접속 (`Code.gs`)
2. `createAll()` 함수를 수동 실행하여 데이터베이스 시트 뼈대 생성
3. `Archive.gs` 의 `setupAutoSyncTrigger()` 함수를 수동 실행하여 15분 자동 동기화 활성화
4. 우측 상단 **[배포] -> [새 배포]** -> 웹 앱(Web App) 설정 후 링크 획득
